PRIVACY

사진은 서버로
전송하지 않습니다.

현재 v1.5는 선택한 사진을 브라우저 메모리에서만 읽고, 브라우저의 Canvas 기능으로 자르기·크기 조정·압축합니다.

현재 버전의 처리 원칙
  • 회원가입이나 로그인이 없습니다.
  • 사진 파일을 별도 서버에 업로드하거나 저장하지 않습니다.
  • 변환 기록을 데이터베이스, 쿠키, Local Storage에 저장하지 않습니다.
  • 서비스 워커를 등록하지 않아 앱 파일을 별도 오프라인 캐시에 고정하지 않습니다.
  • 페이지를 새로고침하거나 닫으면 선택한 사진과 결과가 앱에서 초기화됩니다.

브라우저에서 일어나는 일

사진을 선택하면 브라우저가 파일을 메모리에 읽습니다. 사용자가 정한 구도와 규격에 맞춰 Canvas에서 새 이미지를 만든 뒤 다운로드 가능한 임시 주소를 생성합니다. 원본 해상도 경고와 얼굴 구도 가이드도 브라우저 안에서 계산됩니다.

구도 가이드와 결과 파일

편집 화면의 정수리·눈·턱·어깨 보조선은 화면에서만 그려지며 내려받는 사진에는 포함되지 않습니다. 이 가이드는 일반적인 구도 보조선으로, 기관의 공식 자동 판정이나 접수 승인을 보장하지 않습니다.

AdSense 사이트 인증 준비

v1.5는 배포 설정에 게시자 ID를 입력한 경우 각 HTML의 head에 google-adsense-account 사이트 인증 메타태그를 넣을 수 있습니다. 이 메타태그만으로 광고 스크립트를 불러오거나 사진을 전송하지는 않습니다. 실제 광고 코드는 아직 포함하지 않았습니다.

향후 실제 광고를 추가할 경우

Google AdSense 광고를 실제로 표시하면 Google 광고 서버와의 통신, 쿠키 또는 유사 식별 기술이 사용될 수 있습니다. 그 단계에서는 광고 코드, 동의 절차, 보안 정책과 이 개인정보 안내를 실제 구성에 맞춰 다시 갱신해야 합니다.

외부 링크와 문의

공식 기관 안내와 GitHub Issue는 외부 사이트입니다. GitHub Issue는 공개되므로 증명사진, 이름, 수험번호, 연락처 같은 개인정보를 첨부하지 마세요.
