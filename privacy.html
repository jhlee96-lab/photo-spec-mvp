PRIVACY

사진은 서버로
전송하지 않습니다.

현재 v1.3.1은 선택한 사진을 브라우저 메모리에서만 읽고, 브라우저의 Canvas 기능으로 자르기·크기 조정·압축합니다.

현재 버전의 처리 원칙
  • 회원가입이나 로그인이 없습니다.
  • 사진 파일을 별도 서버에 업로드하거나 저장하지 않습니다.
  • 변환 기록을 데이터베이스, 쿠키, Local Storage에 저장하지 않습니다.
  • 서비스 워커를 등록하지 않아 앱 파일을 별도 오프라인 캐시에 고정하지 않습니다.
  • 페이지를 새로고침하거나 닫으면 선택한 사진과 결과가 앱에서 초기화됩니다.

브라우저에서 일어나는 일

사진을 선택하면 브라우저가 파일을 메모리에 읽습니다. 사용자가 정한 구도와 규격에 맞춰 Canvas에서 새 이미지를 만든 뒤, 다운로드 가능한 임시 주소를 생성합니다. 이 임시 주소는 현재 브라우저 탭 안에서만 사용됩니다.

웹사이트 파일의 업데이트

배포할 때 CSS와 JavaScript 주소에 Git 커밋 기반 버전값을 붙입니다. 새 HTML이 전달되면 브라우저가 이전 버전이 아닌 새 파일을 요청하도록 하기 위한 장치입니다. GitHub Pages의 배포 반영 자체에는 잠시 시간이 걸릴 수 있습니다.

향후 광고·통계를 추가할 경우

현재 버전에는 광고, 방문 통계, 외부 이미지 처리 스크립트가 없습니다. 향후 Google AdSense 같은 제3자 서비스를 추가하면 외부 네트워크 요청, 쿠키 또는 유사 식별 기술이 사용될 수 있으므로 이 안내와 보안 정책을 먼저 갱신해야 합니다.
