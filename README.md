# 사진맞춤 v1.4

공식 기관의 현재 안내를 근거로 원서사진을 브라우저에서 자르고, 크기를 조정하고, 파일 기술 조건과 원본 해상도를 점검하는 정적 웹앱입니다.

## 지원 프리셋

### 국가공무원 응시사진

- 크기: `137 × 177px` (`3.5 × 4.5cm`) 기준
- 형식: JPG 또는 PNG
- 용량: `350KB 미만`(중증장애인 선발시험 제외 일반 안내)
- 공식 출처: 국가공무원 채용시스템 원서접수 안내

### 한국사능력검정시험

- 권장·등록 크기: `120 × 160px` (약 `3 × 4cm`)
- 공식 허용 형식: JPG 또는 GIF
- 앱 출력: JPG
- 공식 공통 최대 용량: 현재 응시안내에 별도 명시 없음
- 공식 출처: 한국사능력검정시험 응시안내 → 사진 등록

### Q-Net 국가자격

- 최소 크기: `300 × 400px 이상`
- 공식 허용 형식: JPEG 또는 JPG
- 앱 출력: 최소 기준을 충족하는 `300 × 400px JPG`
- 공식 공통 최대 용량: 현재 공통 사진등록 안내에 별도 명시 없음
- 포함 예시: 기사·산업기사·기능사·공인중개사 등 Q-Net 접수 종목
- 공식 출처: Q-Net 사진등록 공식 안내

공식 정보 확인일은 `2026-07-26`입니다. 실제 제출 전 해당 종목·회차의 최신 공고를 다시 확인해야 합니다.

## v1.4 변경 사항

- 현재 자르기 영역의 실제 픽셀과 출력 크기를 비교하는 원본 해상도 경고
- 확대 배율에 따라 `해상도 충분`, `가벼운 확대`, `화질 주의`로 구분
- 정수리·눈·턱·어깨와 얼굴 중심을 맞추는 일반 구도 보조선
- 구도 가이드 켜기·끄기 지원
- 가이드 선은 미리보기에만 표시되고 결과 파일에는 포함되지 않음
- 변환 결과에 원본 선택 영역과 화질 상태 표시
- GitHub Pages 사용자 지정 도메인 연결 안내 추가

## v1.3 핵심 기능

- 상단의 중복 프리셋 요약 박스 제거 및 영웅 문구 중앙 정렬
- Q-Net 국가자격 프리셋 추가
- `기준 크기`, `권장 크기`, `최소 크기`를 구분해 표시
- Q-Net 최소 크기 규칙(`300 × 400px 이상`)을 실제 검사 로직에 반영
- 자동 검사와 사진 내용 직접 확인 체크리스트 분리
- 서비스 워커·쿠키·영구 브라우저 저장소 미사용

## 데이터 처리

사진은 서버로 업로드하지 않습니다. 선택한 파일은 현재 브라우저 탭의 메모리와 Canvas에서만 처리됩니다. 새로고침하면 사진과 결과가 초기화됩니다.

현재 앱 코드에는 다음 기능이 없습니다.

- 쿠키 생성 또는 조회
- Local Storage / Session Storage / IndexedDB
- 서비스 워커 및 오프라인 캐시
- 회원가입·로그인·데이터베이스
- 외부 이미지 처리 API

브라우저의 일반 HTTP 캐시는 사용할 수 있지만, 배포 시 각 커밋의 앞 12자리 SHA를 CSS와 JavaScript URL에 넣습니다. 최신 HTML이 반영된 뒤에는 이전 정적 파일을 같은 주소로 재사용하지 않습니다.

## GitHub Pages 배포

1. 저장소 최상위에 프로젝트 파일을 올립니다.
2. `.github/workflows/pages.yml`이 실제로 존재하는지 확인합니다.
3. `Settings → Pages → Source → GitHub Actions`를 선택합니다.
4. `Actions → Test and deploy Pages`에서 `test`와 `deploy`가 모두 성공하는지 확인합니다.
5. 페이지 하단의 `build abcdef123456` 값이 최신 Git 커밋 앞 12자리와 같은지 확인합니다.
