# 사진맞춤 v1.2

공식 기관의 현재 안내를 근거로 원서사진을 브라우저에서 자르고, 크기를 조정하고, 파일 기술 조건을 검사하는 정적 웹앱입니다.

## 지원 프리셋

### 국가공무원 응시사진

- 크기: `3.5 × 4.5cm`, `137 × 177px 기준`
- 형식: JPG 또는 PNG
- 용량: `350KB 미만`(중증장애인 선발시험 제외 일반 안내)
- 공식 출처: 국가공무원 채용시스템 원서접수 안내

### 한국사능력검정시험

- 권장·등록 크기: `120 × 160px`(약 `3 × 4cm`)
- 공식 허용 형식: JPG 또는 GIF
- 앱 출력: JPG
- 공식 공통 최대 용량: 현재 응시안내에 별도 명시 없음
- 공식 출처: 한국사능력검정시험 응시안내 → 사진 등록

공식 정보 확인일은 `2026-07-26`입니다. 실제 제출 전 해당 회차 공지를 다시 확인해야 합니다.

## v1.2 변경 사항

- 한국사능력검정시험 프리셋 추가
- `maxKb: null`을 지원해 공식 용량 제한이 없는 경우 임의 제한을 만들지 않음
- `기준 크기`와 `권장 크기`를 구분해 표시
- 공식 허용 형식과 앱이 실제 생성하는 형식을 분리
- 자동 검사와 사용자가 직접 확인할 사진 내용 조건을 분리
- 선택 프리셋에 맞춰 상단 요약·공식 출처·출력 형식을 동적으로 변경
- 한국사 프리셋은 공식 허용 형식 중 JPG로만 안전하게 출력
- 자동 테스트 23개

## 데이터 처리

사진은 서버로 업로드하지 않습니다. 선택한 파일은 현재 브라우저 탭의 메모리와 Canvas에서만 처리됩니다. 새로고침하면 사진과 결과가 초기화됩니다.

현재 앱 코드에는 다음 기능이 없습니다.

- 쿠키 생성 또는 조회
- Local Storage / Session Storage / IndexedDB
- 서비스 워커 및 오프라인 캐시
- 회원가입·로그인·데이터베이스
- 외부 이미지 처리 API

브라우저의 일반 HTTP 캐시는 사용할 수 있지만, 배포 시 각 커밋의 앞 12자리 SHA를 CSS와 JavaScript URL에 넣습니다. 최신 HTML이 반영된 뒤에는 이전 정적 파일을 같은 주소로 재사용하지 않습니다.

## GitHub Pages 배포

1. 저장소 최상위에 프로젝트 파일을 올립니다.
2. `.github/workflows/pages.yml`이 실제로 존재하는지 확인합니다.
3. `Settings → Pages → Source → GitHub Actions`를 선택합니다.
4. `Actions → Test and deploy Pages`에서 `test`와 `deploy`가 모두 성공하는지 확인합니다.
5. 테스트 로그에 `pass 23`, `fail 0`이 표시되는지 확인합니다.
6. 페이지 하단의 `build abcdef123456` 값이 최신 Git 커밋 앞 12자리와 같은지 확인합니다.
