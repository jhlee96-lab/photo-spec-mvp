# 사진맞춤 — 국가공무원 응시사진 1차 MVP

사진을 브라우저에서 직접 자르고, 지정한 픽셀과 파일 용량에 맞춰 JPG 또는 PNG로 내려받는 정적 웹앱입니다. 회원가입, 서버 업로드, 데이터베이스가 없습니다.

## 반영한 국가공무원 공식 기술 규격

2026-07-25에 국가공무원 채용시스템의 현재 원서접수 안내를 확인했습니다.

- 파일 형식: JPG 또는 PNG
- 크기: 3.5 × 4.5cm, 137 × 177px 기준
- 파일 용량: 350KB 미만
- 용량 기준 예외: 중증장애인 선발시험 제외

공식 출처:

- https://gongmuwon.gosi.kr/oprut/AppApAplfSbmsnAplfRcptGd.do

사진 구도 관련 참고사항은 인사혁신처의 2019년 공식 안내를 별도로 참고했습니다. 해당 게시물은 현재 기술 업로드 규격과 달리 오래된 안내이므로 앱에서는 참고사항으로만 표시합니다.

- https://www.mpm.go.kr/mpm/info/infoJobs/jobsBoard/?boardId=bbs_0000000000000118&cntId=22&mode=view

## MVP 기능

- 국가공무원 응시사진 프리셋
- 사용자 지정 가로·세로·최대 용량
- JPG, PNG, WebP 원본 업로드
- 드래그 위치 조정, 확대, 90도 회전
- 정확한 목표 픽셀로 크기 조정
- JPG 자동 품질 탐색으로 목표 용량 이하 압축
- 결과 규격 검사 및 파일 다운로드
- 모바일 반응형 UI
- 모든 이미지 처리를 브라우저 내부에서 수행
- 서비스 워커 없음: 배포 변경 사항이 오래된 캐시에 갇히지 않음

## 지원하지 않는 기능

- HEIC 직접 변환
- 얼굴 위치·배경색·최근 촬영 여부 자동 검사
- 여권·비자 등 다른 기관 프리셋
- 서버 저장 및 회원가입
- 실제 AdSense 광고

## 로컬 실행

ES 모듈을 사용하므로 파일을 더블클릭하지 말고 간단한 로컬 서버에서 엽니다.

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다.

## 테스트

```bash
npm ci
npm test
npm run check
```

## GitHub Pages 배포

1. 새 GitHub 저장소를 만듭니다.
2. ZIP을 푼 내부 파일을 저장소 최상위에 업로드합니다.
3. `Settings → Pages → Source → GitHub Actions`를 선택합니다.
4. `Actions → Test and deploy Pages`가 성공하는지 확인합니다.

## 개인정보 관련

현재 앱은 사진을 네트워크로 전송하지 않습니다. 다만 향후 방문 분석 도구나 광고를 추가하면 제3자 스크립트, 쿠키, 개인정보 처리 안내와 동의 구성을 다시 검토해야 합니다.

## 주의

이 도구는 픽셀, 형식, 용량의 기술 조건만 검사합니다. 최종 제출 가능 여부를 보장하지 않으며 실제 원서접수 직전에 반드시 해당 시험의 공식 안내를 다시 확인해야 합니다.
